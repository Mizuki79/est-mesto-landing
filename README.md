# Есть место

Лендинг культурного проекта для студентов Москвы. Дизайн «После пар»: афишная типографика, розовый, лайм и театральная фотография.

HTML, CSS и vanilla JavaScript. Без сборки, runtime-зависимостей и серверной части. Откройте `index.html` в браузере. Все ассеты локальные, пути относительные; сайт работает в подкаталоге GitHub Pages.

## Публикация

Репозиторий: `Mizuki79/est-mesto-landing`. В Settings → Pages выберите Deploy from a branch → main → / (root). Адрес: https://Mizuki79.github.io/est-mesto-landing/.

Обновление: коммит и push в main. После коммита GitHub Pages автоматически публикует изменения. Файл `.nojekyll` отключает обработку Jekyll.

## Содержимое

- `index.html`: контент, SEO, доступная семантика и диалоги.
- `styles.css`: адаптивные стили; уменьшение анимаций по системной настройке.
- `app.js`: меню, фильтры и модальные окна. Без отправки персональных данных.
- `*.webp`: оптимизированные изображения для проекта. Изображения созданы с помощью генерации и не являются фотографиями конкретных площадок или объявлениями о реальных событиях.
- `oswald-600.ttf`, `golos-400.ttf`: локальные шрифты Oswald и Golos Text, SIL Open Font License, см. `OFL-Oswald.txt` и `OFL-Golos.txt`.
- `arrow-up-right.svg`: Lucide, ISC, см. `LICENSE-Lucide.txt`.

Все основные кнопки ведут на https://t.me/est_mesto_msk_bot. Направления на сайте не выдают себя за актуальную афишу: даты, места и условия доступны в боте. Сервер бота и его данные не входят в этот репозиторий.

## Аналитика

Рекламные счётчики не подключены: идентификатор Яндекс.Метрики или Google Analytics владельцем не предоставлен. Перед рекламной кампанией нужно подключить реальный счётчик и согласовать обработку данных. В лендинге нет вымышленных ID и скрытой отправки данных.

## Проверки

Статический smoke-тест: `node --check app.js`. Браузерные проверки выполняются отдельно через Playwright и не добавляют зависимости в сайт. Результаты проверки указаны в `QA.md`.
